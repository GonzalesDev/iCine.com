### 1. Visão Geral do Projeto (iCine)
O iCine é uma plataforma pessoal de filmes que funciona como um misto de Letterboxd (diário e comunidade) com Netflix/Stremio (agregador de streaming). Ele permite ao usuário organizar o que quer assistir, ver o que já assistiu, interagir com amigos (estilo rede social), assistir a edições de filmes (estilo TikTok/Reels) e dar play direto em filmes usando o Stremio ou Web Players embedados.

### 2. Stack Tecnológico
- **Frontend:** HTML5, CSS3 Vanilla (sem frameworks como Tailwind ou Bootstrap) e JavaScript Vanilla.
- **Backend / BaaS:** Supabase (Autenticação, Banco de Dados PostgreSQL e Storage para imagens).
- **APIs Consumidas:** 
  - TMDB API (The Movie Database) para busca de filmes, capas, sinopses, trailers e provedores.
  - Groq API (modelo Llama 3) para o Chatbot de IA integrado.
- **Arquitetura:** Single Page Application (SPA) estruturada em Abas ocultas/ativas gerenciadas por JavaScript (`.aba.ativa`).

### 3. Estrutura do Banco de Dados (Supabase)
As principais tabelas que utilizamos são:
- `meus_filmes`: Armazena os filmes do usuário (coluna `grupo` define se é 'quero' ou 'ja' assistiu).
- `playlists`: Listas criadas pelos usuários, podendo ser públicas (aparecem no Feed global).
- `cenas_shorts`: Feed de vídeos curtos verticais (contém arrays de `curtidas` e `comentarios`).
- `perfis`: Guarda o `@username` atrelado ao `user_id` de autenticação.
- `amizades`: Sistema de amigos com `solicitante_id`, `destinatario_id` e `status` ('pendente' ou 'aceite').
- `recomendacoes_amigos`: Caixa de entrada (inbox) onde usuários enviam dicas de filmes uns aos outros.

### 4. Design System & UI/UX
- **Tema:** Dark UI imersiva (Fundo principal: `#030712`, com toques em neon roxo `--purple: #8b5cf6` e rosa `--pink: #ec4899`).
- **Estética:** Uso intenso de *Glassmorphism* (Efeito Vidro) com `backdrop-filter: blur(10px)`, fundos semi-transparentes e bordas sutis.
- **Modal de Detalhes:** É o coração do app. Quando se clica num filme, abre um modal imersivo ocupando 90% da tela. O topo (`.detalhe-hero`) tem proporção 16:9, cantos inferiores arredondados (25px) e roda o trailer oficial do YouTube em auto-play silencioso de fundo, coberto por um degradê escuro.

### 5. Funcionalidades Principais Atuais
- **Abas de Navegação:** Listas (Watchlist/Playlists), Explorar (Pesquisa TMDB e Top 10 Streaming), Cenas (Scroll vertical estilo TikTok), Feed (Playlists da comunidade) e Amigos (Rede social, adicionar amigos, recomendar filmes).
- **Chat IA:** Um FAB (Floating Action Button) arrastável que abre um chatbot cinéfilo.
- **Assistir:** 
  1. *Stremio:* Deep links customizados para abrir o filme direto no Stremio com addons dublados (`stremio://detail/movie/{imdb_id}`).
  2. *Online:* Iframe com Web Players piratas baseados no TMDB ID (ex: VidSrc e MultiEmbed).

### 6. Onde Paramos / Próximo Desafio
